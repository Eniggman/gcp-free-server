## 📌 О проекте

Пошаговое практическое руководство по запуску круглосуточного Linux-сервера в **Google Cloud Compute Engine** по программе  **Always Free Tier** .

Идеально для запуска AI CLI-агентов, телеграм-ботов, фоновых скриптов и удаленного управления через веб-дашборд.

* **Философия бюджета:** \$0.00 личных средств. Расходы на 100% покрываются ежемесячными подарочными купонами \$10 от Google Developer Program при подписке Google AI Pro.

### 🥊 Минусы Spot-сервера и как мы их законтрили (с бесплатным доменом на 1 год)

| ⚠️ Минус Spot                                                  | В чём физическая проблема                                                                                                                                                                              | 🛡️ Как мы это законтрили (Решение)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| :-------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Внезапный отзыв ВМ (Preemption)**          | Google Cloud может в любой момент выключить машину, забрав ресурсы для платных клиентов.                                                                      | **Контра:** **100% Serverless Event-Driven Auto-Restarter.**Событие `compute.instances.preempted` из Audit Logs перехватывается нашим **Cloud Logging Sink** ➔ отправляется в **Pub/Sub** ➔ будит **Cloud Function (512MB)**. Функция сама подаёт команду на запуск, а в Telegram шлёт отчёт с кнопкой ручного перезапуска.                                                                                                         |
| **2. Смена IP-адреса при перезапуске** | Динамический IP на Spot дешёвый (\$1.83/мес вместо \$3.65), но меняется при каждом выключении/включении сервера.                                    | **Контра 1: Бесплатный домен на 1 год.** Различные корпорации часто дают бесплатный домен на 12 месяцев (GitHub Student Developer Pack, акции Namecheap, Freenom, Cloudflare). К домену настраивается Dynamic DNS (DDNS через Cloudflare API): при смене внешнего IP скрипт обновляет DNS-запись за 2 секунды, и сервер всегда доступен по красивому постоянному адресу! |

Никакого спама в API.                                                                                                                                                                               |

## ⚠️ Внешний IP: Почему категорически НЕЛЬЗЯ отключать External IP

> [!CAUTION]
> **Никогда не выбирайте `External IP: None` в настройках сети!**

1. **Сервер лишается выхода в интернет:** Без внешнего адреса на ВМ перестанут работать `apt update`, `pip install`, `npm install`, обращения к GitHub, Telegram API и языковым моделям Gemini/OpenAI.
2. **Ловушка Cloud NAT Gateway (~\$32+/месяц):** Единственный штатный способ дать интернет машине без внешнего IP в GCP — поднять Cloud NAT Gateway. Абонплата за него составляет **~\$32.00 в месяц**, что моментально уничтожит нулевой бюджет!
3. **Динамический IP (Ephemeral IPv4) — бесплатен в Always Free и дешев на Spot:** В Always Free один динамический IP для `e2-micro` бесплатен (\$0.00), а для Spot VM действует **скидка 50%** (\$0.0025/час = ~\$1.83/мес вместо \$3.65).

## 🔄 Архитектура Serverless Auto-Restarter v2.0 (для Spot VM)

Для тех, кто выбрал **Spot VM** («План Б» с 2 ГБ RAM), реализован полностью бессерверный сторож без нагрузки на CPU сервера:

```
[Google Cloud: Audit Logs (compute.instances.preempted)] 
                         │
                         ▼
[Cloud Logging Sink: spot-preemption-sink]
                         │
                         ▼
[Pub/Sub Topic: spot-preempted-events]
                         │
                         ▼
[Push Subscription: Лестница повторов 1м ➔ 5м ➔ 10м ➔ 20м ➔ 40м ➔ 60м]
                         │
                         ▼
[Cloud Function: spot-restarter (Python, 512MB RAM)] 
             ├──► Автозапуск: Compute Engine API instances.start()
             └──► Telegram Bot: Оповещение + кнопка [ 🚀 Включить вручную ]
```
